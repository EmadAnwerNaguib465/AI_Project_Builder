# Local Fonts

Latin subsets served locally so the interface does not depend on external font requests.

- Bricolage Grotesque, variable 400-800: Google Fonts / SIL Open Font License.
- Manrope, variable 400-800: Google Fonts / SIL Open Font License.
- IBM Plex Mono, 400, 500, 600: Google Fonts / SIL Open Font License.

Original sources: https://github.com/google/fonts/tree/main/ofl
The corresponding license files are included in this directory.
